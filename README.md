# Irregular Verbs Wallpaper

Обои для экрана блокировки iPhone, которые 3 раза в день показывают неправильные глаголы английского: новый глагол утром, «вспомни формы» днём, «проверь себя» вечером.

- **Топ-100** самых частых неправильных глаголов, с переводом на русский.
- **Интервальные повторения:** каждый глагол возвращается через +1, +3, +7 и +21 день.
- **Активное вспоминание:** днём формы скрыты (`spend → ? → ?`), вечером видны ответы.
- **Подсветка изменений:** s*i*ng → s*a*ng → s*u*ng.
- **Цвет группы:** AAA (cut–cut–cut), ABB (make–made–made), ABA (come–came–come), ABC (go–went–gone), AAB (beat–beat–beaten).
- Одно разрешение **1320×2868** подходит ко всем iPhone с Face ID. Текст стоит в безопасной зоне: часы и кнопки его не перекрывают.

Курс длится **121 день** (100 дней новых глаголов + 21 день на последние повторения).

## Распорядок дня

| Время | Карточка |
|---|---|
| 08:00 | **NEW**: новый глагол дня, все три формы |
| 13:00 | **RECALL**: глаголы на повторении, формы скрыты |
| 19:00 | **ANSWER**: те же глаголы с ответами |

Картинки лежат в `images/day-XXX-N.png`, где `XXX` — день курса (001–121), `N` — слот (1, 2, 3).
Дата старта нигде не зашита: каждый пользователь задаёт свою в команде на iPhone.

## Настройка на iPhone (≈5 минут)

### 1. Команда «Irregular Verbs»

Приложение **Команды** → **+** → назовите `Irregular Verbs` и добавьте действия по порядку:

1. **Дата**: укажите дату старта (например, сегодняшнюю). Назовите результат `Старт`.
2. **Получить время между датами**: от `Старт` до `Текущая дата`, в **днях**.
3. **Вычислить**: `Время между датами` **+ 1001**.
   (Например, на 47-й день получится `1047`; лишняя «1» спереди нужна, чтобы получить номер с ведущими нулями.)
4. **Сопоставить текст**: шаблон `\d{3}$` в `Результат вычисления`. Получится `047`.
5. **Форматировать дату**: `Текущая дата`, формат **Свой** → `H` (час 0–23).
   Сразу после добавьте **Число** со значением `Форматированная дата`: дата форматируется в текст, а «меньше» работает только с числом.
6. **Если** `Число` **меньше** `13`:
   - **Текст** `1`
   
   **Иначе:**
   - **Если** `Число` **меньше** `19` → **Текст** `2`, **иначе** → **Текст** `3`.
   
   Результат блока назовите `Слот`.
7. **URL**:
   ```
   https://raw.githubusercontent.com/kamil-stories/irregular-verbs-wallpaper-/main/images/day-[Совпадения]-[Слот].png
   ```
   (`[Совпадения]` и `[Слот]` — переменные из шагов 4 и 6.)
8. **Получить содержимое URL**.
9. **Установить обои**: изображение = `Содержимое URL`, экран **Экран блокировки**.
   Разверните действие и **выключите «Показать превью»**, иначе команда будет ждать подтверждения.

> До старта и после 121-го дня файла нет, и команда просто ничего не сменит.

Запустите команду вручную один раз и проверьте, что обои сменились.

### 2. Три автоматизации

**Команды** → вкладка **Автоматизация** → **+** → **Время суток**:

| Время | Повтор | Действие |
|---|---|---|
| 08:00 | Ежедневно | Запустить команду `Irregular Verbs` |
| 13:00 | Ежедневно | Запустить команду `Irregular Verbs` |
| 19:00 | Ежедневно | Запустить команду `Irregular Verbs` |

В каждой включите **«Запускать сразу»** и выключите **«Уведомлять при запуске»**.

Время можно поменять, главное — чтобы утренний запуск был до 13:00, дневной между 13:00 и 19:00, вечерний после 19:00.

### Как поделиться с другом

1. В команде нажмите **ⓘ** → **Настроить импорт** → для действия **Дата** включите вопрос «Когда начинаем?».
2. **Поделиться** → **Скопировать ссылку iCloud** → отправьте другу.
3. Друг откроет ссылку, укажет свою дату старта и создаст три автоматизации из шага 2. Автоматизации iOS передать нельзя, только команды.

## Настройка на iPhone: интерфейс на английском

### 1. Команда

**Shortcuts** → **+** → назовите `Irregular Verbs`. Через **Search Actions** добавьте по порядку:

1. **Date**: дата старта (например, сегодняшняя).
2. **Get Time Between Dates**: `Get` **Days** `between` **Date** `and` **Current Date**.
3. **Calculate**: `Time Between Dates` **+** `1001`.
4. **Match Text**: шаблон `\d{3}$`, текст `Calculation Result`. Получится `047`.
5. **Format Date**: **Current Date**, **Date Format** → **Custom**, **Format String** → `H`.
   Сразу после добавьте **Number** со значением `Formatted Date`: Format Date выдаёт текст, а **is less than** есть только для чисел.
6. **If**: `Number` **is less than** `13`
   - внутри: **Text** `1`;
   - в **Otherwise**: вложенный **If** `Number` **is less than** `19` → **Text** `2`, в его **Otherwise** → **Text** `3`.

7. **URL**:
   ```
   https://raw.githubusercontent.com/kamil-stories/irregular-verbs-wallpaper-/main/images/day-[Matches]-[If Result].png
   ```
   `[Matches]` и `[If Result]` (внешнего If) вставляются через **Select Variable**.
8. **Get Contents of URL**.
9. **Set Wallpaper** (в новых iOS — **Set Wallpaper Photo**): **Contents of URL**, экран **Lock Screen**.
   Раскройте параметры стрелкой **›**, выключите **Show Preview** (и **Crop to Subject**, если есть).

Нажмите **▶︎** и проверьте, что обои сменились.

### 2. Автоматизации (3 раза)

**Automation** → **+** → **Time of Day**:
- время **8:00 AM**, затем **1:00 PM**, затем **7:00 PM**;
- **Repeat** → **Daily**;
- **Run Immediately**, выключить **Notify When Run**;
- **Next** → выбрать **Irregular Verbs** → **Done**.

### 3. Как поделиться

1. В команде **ⓘ** / **Details** → **Setup** → **Add Import Question** → действие **Date**, вопрос «Когда начинаем?».
2. **Share** → **Copy iCloud Link** → отправьте ссылку.

> Названия в шаге 3 и действие **Set Wallpaper** могут немного отличаться в разных версиях iOS.

## Для разработчика

```bash
pip3 install playwright && python3 -m playwright install chromium
python3 src/build.py --samples 47   # 3 карточки одного дня → samples/
python3 src/build.py --all          # все 363 картинки → images/ (~4 мин)
```

- `data/verbs.json` — список глаголов (порядок = порядок изучения).
- `src/build.py` — расписание, подсветка, рендер (HTML → PNG через Playwright).
- `src/style.css` — дизайн карточек.
